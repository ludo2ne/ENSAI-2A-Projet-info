Instructions

  • Written exam
  • Duration: 2 hours
  • One A4 sheet of handwritten notes (front and back) allowed
  • No calculator
ImportantRead Before Starting
  • You can answer the exercises in any order.
  • Within each exercise, the questions are not necessarily ordered by increasing difficulty.
  • Unless otherwise stated, the questions expect short answers.
  • Strictly follow the instructions. If a question seems unclear, state your assumptions on your answer sheet.
  • When code is required, follow the basic language conventions (keywords, indentation, etc.). Syntax errors due to handwriting will be tolerated. If you do not remember the exact name of a Python method, you may use pseudocode.
  • Unless explicitly requested, code documentation is not required.

Good Luck!

  1. Following the documentation, write the code for this method.
game_factory.py
class GameModeFactory:
    @classmethod
    def get_mode(cls, game_mode: str) -> GameMode:
        """
        Returns the corresponding GameMode object.
        Args:
            game_mode (str): The identifier of the game mode (e.g., 'coinflip', 'dice').
        Returns:
            CoinFlipMode or DiceMode: An instance of a class implementing GameMode.
        Raises:
            ValueError: If the requested game_mode is not supported."""
        if game_mode == "coinflip":
            return CoinFlipMode()
        elif game_mode == "dice":
            return DiceMode()
        else:
            raise ValueError(f"Unknown game mode: {game_mode}")

4 Git (4 points)

Sofia has just joined your development team as a junior developer.

  1. Which Git command should she use to retrieve a local copy of the repository?

She should clone the repository:

git clone https://github.com/goodfood/ten-vegetables-per-day.git

# If she use a token
git clone https://$TOKEN@github.com/goodfood/ten-vegetables-per-day.git
  1. What is the purpose of using a personal access token when authenticating to GitHub over HTTPS?

A personal access token is used to authenticate the user when communicating with GitHub over HTTPS.

  1. Describe the Git workflow you use each week to update the shared report project file.

If you are not working on the project: please state this and imagine that each week you have to fill in a file containing a task list and send it to the shared repository.

A possible workflow is:

git pull
# I then modify the report file.
git status
git add .
git commit -m "Update weekly report"
git push

Sofia modifies src/vegetables.py and tries to push her changes, but Git says “Everything up-to-date” / “Nothing to push”.

  1. What does she need to do before pushing her changes?

She has modified a file, so she needs to add and commit the changes first:

git add src/vegetables.py  # or git add .
git commit -m "Update vegetables"

Then she should be able to push.

Sofia tries to push her commit again, but this time Git displays a different message.

! [rejected]        main -> main (fetch first)
error: failed to push some refs to 'https://github.com/goodfood/ten-vegetables-per-day.git'
hint: Updates were rejected because the remote contains work that you do
hint: not have locally. This is usually caused by another repository pushing
hint: to the same ref. You may want to first integrate the remote changes.
  1. Why is Sofia getting this message? What should she do to resolve the situation?

The remote repository contains commits that are not present in her local repository.

For example, another developer may have pushed changes since Sofia’s last git pull.

She should first retrieve the remote changes using git pull.
If there is no conflict, she can then push her changes.
If a merge conflict occurs, she must resolve the conflict manually, then add and commit the resolution before pushing again.

  1. Is the project necessarily lost? Explain why.

No.

Stan still has a local copy of the Git repository. A local Git repository contains the project’s files and its Git history. The project can therefore be recovered from Stan’s local repository.
